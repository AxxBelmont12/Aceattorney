# Avatar Studio 0.14.0

- Instalador para Windows de 64 bits, con accesos directos y desinstalador.
- Consulta de nuevas versiones desde GitHub Releases, con aviso en la aplicación.
- Descarga verificada y botón para instalar y reiniciar cuando lo decidas.
- Se conservan proyectos, biblioteca, preferencias y modelo de transcripción.
- Incluye las funciones de la versión 0.13: audio a texto local, fragmentos sincronizados, línea de tiempo, modo juicio, fondos y exportación de video.

Descarga **Instalar-Axx-Belmont-Avatar-Studio.exe**. Basta ese archivo para instalar.
Si usabas una copia portátil, instala esta versión una vez para activar las actualizaciones.
